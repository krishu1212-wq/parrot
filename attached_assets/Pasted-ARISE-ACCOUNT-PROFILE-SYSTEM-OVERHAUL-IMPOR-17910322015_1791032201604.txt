Implement ONLY the account/profile changes described below.

3. NEW GUEST
==================================================

When the user selects NEW GUEST:

Create a completely NEW unique profile.

Fresh default state MUST be:

Level: 1
XP: 0
Rank: E
Streak: 0
Phase: initial Phase 1 state
Daily quest progress: 0
Achievements: empty
Inventory: empty
Equipment: empty
Boss history: empty
Gate progress: initial/locked
Study history: empty
Personal records: default/empty

Generate a unique Account ID automatically.

Example format:

ARISE-XXXX-XXXX

The ID must be sufficiently random and unique.

Do NOT reuse an old profile ID.

Do NOT accidentally restore old AsyncStorage/local data.

Do NOT restore another user's cloud snapshot.

==================================================
4. ACCOUNT CODE / ID
==================================================

Each profile gets its own unique Account Code/Account ID.

The Account Code is the recovery identifier for the profile.

Example:

ARISE-7K4M-92PX

The app must be able to verify the entered code against the account's cloud record.

Do NOT simply trust whatever ID the user types.

Verification must happen against the actual stored account/profile record.

Invalid code:
Show an ARISE-style error:

"INVALID ACCOUNT CODE"

Do not load any data.

Valid code:
Show:

"ACCOUNT FOUND"

Then show a short confirmation/recovery screen before restoring the profile.

10. DATA OWNERSHIP / SECURITY
==================================================

This is critical.

Every cloud profile must have a stable unique internal user/profile identifier.

Do not use the Account Code itself as the only authorization mechanism.

The backend must verify that the requested profile exists and that the restore operation is permitted.

Do not store passwords.

Do not expose backend secrets in the client.

Do not allow arbitrary client-side profile IDs to overwrite another user's cloud data.

Keep owner checks and existing persistence protections.
