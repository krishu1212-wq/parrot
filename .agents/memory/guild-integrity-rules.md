---
name: Guild integrity rules
description: Product rules for ARISE Guilds, Sunday contributions, reviews, and rewards.
---

- A Guild has at most 12 active members. Sunday tournament dates use Asia/Kolkata.
- Each member may submit up to three distinct saved qualifying study-event IDs per Sunday. The server checks saved event records; client XP and correctness are never evidence.
- Leader review awards Guild-side contribution points only. Three distinct approved contributors unlock the shared “Sunday Constellation” achievement. Guild activity never changes personal XP, academic progress, accuracy, or real-world money.
- Leaving retains history. An empty Guild closes; when its leader leaves, leadership transfers to the earliest active member.
- Optional notes provide context, not proof. Do not expose fake upload controls; evidence files require a private storage path compatible with the active ARISE profile authentication.

**Why:** The project requires honest study records, small circles, and fictional Guild rewards without changing members’ personal progress or payout eligibility.

**How to apply:** Enforce membership, event eligibility, review, contribution, and reward rules on the server. If the three-event cap is ambiguous across multiple Guilds, resolve that scope before changing the existing limit.
